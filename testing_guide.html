Testing Guide — Build, Deploy, and Validate on ThinkPad T480

Before you start: This guide walks you through building the single-binary release, deploying it to your T480 as Administrator, and testing all 8 critical GUI bug fixes. Follow each scenario in order to verify the app works end-to-end.

Build & Deployment

Release Build

Create a self-contained, single-file binary:

dotnet publish TPFan.GUI/TPFan.GUI.csproj ` --configuration Release ` --runtime win-x64 ` --self-contained true ` -p:PublishSingleFile=true ` -p:IncludeNativeLibrariesForSelfExtract=true ` --output ./publish/tpfan

Output: ./publish/tpfan/TPFan.GUI.exe (~200MB+ self-extracting binary containing .NET runtime, inpoutx64.dll driver interface, and all dependencies)

Test Environment

Component Requirement
Hardware Lenovo ThinkPad T480 (or equivalent EC-capable laptop)
OS Windows 11 (or Windows 10 21H2+)
Privileges Administrator (required for EC writes)

Test Scenarios

Scenario 1: First Launch (Admin Privileges)
Run as Administrator
Start-Process -FilePath ".\publish\tpfan\TPFan.GUI.exe" -Verb RunAs

Or right-click TPFan.GUI.exe → Run as Administrator

Expected state:
  • Window opens with header "🌀 TPFan-Win"
  • Status card: Temp badge (circle) with current CPU temp in °C (e.g., "45°"), RPM value, Speed %, Mode in green
  • Fan Control card: Toggle labeled "A" (Auto), "Current: Auto" label, NO slider visible yet
  • Fan Curve canvas: Blue line graph showing the fan curve
  • Bottom: "🟢 Hardware connected" in green

Scenario 2: Toggle to Manual Mode
Click the "A" toggle switch

Watch it animate smoothly to "M" (blue background)

Expected state after toggle:
  • Toggle shows "M" and is blue
  • Slider appears below with large % text in center
  • Slider bar with "0%" | "50%" | "100%" labels
  • Status card: "Mode: Manual" in orange
Verify:
Scenario 3: Slider Snaps to Fan Curve
Move slider slowly left and right

Watch the large % text change as you drag

Expected behavior:

Slider should snap to discrete points, not slide smoothly. Typical snap points for T480: 0%, 20%, 30%, 40%, 50%, 60%, 70%, 80%, 100%. Each jump corresponds to a fan curve threshold temperature.

Verify:
Scenario 4: Fan Hardware Responds
Set slider to 100% (max fan)

Move slider all the way right

Expected:
  • Fan spins audibly faster (loud whoosh from vents)
  • "RPM:" value increases in real-time
  • "Speed: 100%" in status card
  • Status shows "Manual" in orange
Verify:
Set slider to 0% (min fan)

Move slider all the way left

Expected:
  • Fan slows to minimal (nearly silent)
  • RPM drops significantly
  • Speed % shows 0-5%
Verify:
Scenario 5: Real-time Graph Update
Set slider to a mid-range value (e.g., 50%)

Keep window visible for 30 seconds and watch the fan curve canvas

Expected:
  • Orange dot on curve moves as CPU temp fluctuates
  • Dot position = current temp (x-axis) vs. current speed (y-axis)
  • Dot moves even if slider doesn't change (as temp varies)
  • Graph redraws every 2 seconds
Verify:
Scenario 6: Toggle Back to Auto Mode
Click the "M" toggle to return to Auto

Watch it animate back to "A" (gray background)

Expected state:
  • Toggle shows "A" and is gray
  • Slider hidden (not just disabled — completely gone)
  • Mode shows "Auto" in green
  • RPM/Speed % continue to update from sensors
  • Fan returns to firmware control (speed may adjust)
Verify:
Scenario 7: Run Without Admin Privileges (Graceful Degradation)
Run TPFan.GUI.exe as regular user (NOT admin)

Do not right-click "Run as Administrator"

Expected state:
  • Window still opens
  • Temperature/RPM/Speed % still update from sensors
  • Toggle exists but does nothing (disabled)
  • Slider always hidden
  • Status: "⚠️ Hardware unavailable" in red
  • Console: "EC fan control: unavailable"
Verify:
Scenario 8: Close and Reopen
Close window while in Manual mode (slider active)

Then immediately reopen as Administrator

Expected:
  • Fan returns to Auto mode on close (Dispose() resets EC)
  • Toggle opens in "A" state
  • Slider hidden
  • No stale fan overrides lingering

Known Limitations

1. VBS / Hyper-V Blocks MSR

If Windows has Virtual Machine Platform (Hyper-V) enabled, temperature sensors may not be available:

  • Symptom: Temperature reads 0°C or stays at ~30°C steady
  • Cause: LibreHardwareMonitor cannot read MSR (CPU temperature register)
  • Fallback: Uses ACPI WMI thermal zone (less accurate)
  • Workaround: Disable Hyper-V if accurate temp is needed

2. inpoutx64.sys Driver Not Installed

If the EC driver is missing:

  • Symptom: Slider moves but fan doesn't respond
  • Cause: inpoutx64.sys not installed or loaded
  • Workaround: Check Windows Device Manager for unknown devices; manually install WinIO driver if needed

3. Fan Curve Not Detected

If curve detection fails:

  • Symptom: Status shows "Hardware unavailable", slider has no snap points
  • Fallback: Slider ranges 0-100% but snaps are disabled

Troubleshooting

Fan Stuck at High Speed After Crash

Fix:

  1. Restart the app as Administrator
  2. Set toggle to "A" (Auto) — this calls ResetToAutoAsync()
  3. Close app — this also resets on exit

Fan Unresponsive (Slider Moves But Fan Doesn't)

Diagnostics:

  1. Check console: is SetFanSpeedOverrideAsync being called?
  2. Confirm you're running as Administrator
  3. Check Windows Device Manager for driver errors
  4. Verify EC register 0x2F changed (use RWEverything if available)

Temperature Always 0°C

Diagnostics:

  1. Check if Hyper-V is enabled (VBS blocks MSR)
  2. Check console for fallback: "Using ACPI WMI thermal zone"
  3. Try LibreHardwareMonitor directly to see if it detects sensors
