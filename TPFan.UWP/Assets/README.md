# UWP Assets Directory

This directory contains visual assets for the UWP app:

## Required Files (add these manually):

- `StoreLogo.png` (50x50)
- `Square150x150Logo.png` (150x150)
- `Square44x44Logo.png` (44x44)
- `Wide310x150Logo.png` (310x150)
- `SplashScreen.png` (620x300)

## How to Generate

You can use any image editor or use the Visual Studio asset generator:

```bash
# In Visual Studio:
# Project → Store → Create App Icons
```

For development, you can use simple placeholder images or comment out the
manifest references until assets are created.
